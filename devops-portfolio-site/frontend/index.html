Architecture

        
One request, two Free Tier services, zero servers to patch.

        

          The frontend is static assets on S3 behind CloudFront for TLS, caching and a global edge.
          The one dynamic feature — the visitor counter above — is a Lambda function behind API
          Gateway, backed by DynamoDB. Nothing here needs an always-on EC2 instance or a NAT gateway,
          which is where Free Tier accounts usually start racking up charges.

CI/CD

        
Every push to main runs the same eight stages.

        

          Two independent GitHub Actions workflows — one for the frontend, one for the backend —
          only run when files in their own directory change. Both authenticate to AWS with a
          short-lived OIDC token, never a stored access key.

Stack

        
What's actually running underneath.

        

          

            
Compute & delivery

            
S3 static hosting, CloudFront (OAC, no public bucket), Lambda (container image), API Gateway HTTP API.

          

          

            
Data

            
DynamoDB on-demand table for the visitor counter — no provisioned capacity to forget about.

          

          

            
Infrastructure as code

            
Terraform, remote state in a versioned S3 bucket with a DynamoDB lock table.

          

          

            
CI/CD

            
GitHub Actions, OIDC federation to AWS, environment-gated approvals for Terraform apply.

          

          

            
Containers

            
Multi-stage Docker builds for local parity; the Lambda ships as a container image via ECR.

          

          

            
Observability & security

            
CloudWatch alarms + dashboard, AWS Budgets alert, least-privilege IAM, Dependabot, CodeQL, tfsec.

          

        

      

    


    
    

      

        
Cost

        
Designed to stay inside the Free Tier.

        

          Nothing here runs on an always-on server. The table below is the honest cost model,
          including what happens after the 12-month Free Tier window ends.
        

        

          

            
              
ServiceFree Tier allowanceTypical portfolio usageCost after 12 months

            
            
              
S35 GB storage, 20k GET/month< 5 MB, low traffic~$0.01–0.05/mo

Lambda1M requests/mo — always freeHandful of requests/day$0.00

              
API Gateway (HTTP API)1M requests/moWell under limit~$0.00–0.05/mo

              
DynamoDB25 GB, on-demand — always free tier applies to provisioned onlyA handful of items~$0.00–0.02/mo

              
ECR500 MB-month private storage (12 mo)One small image~$0.10/mo per extra GB

              
Route 53 (optional)Not covered by Free Tier1 hosted zone, if used$0.50/mo + registrar fee

            
          

        

        

          A Terraform-managed AWS Budgets alert emails a warning at 80% of a
          configurable threshold (default $2), so a misconfiguration gets caught before it becomes a bill.
